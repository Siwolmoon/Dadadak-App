# 다다닥

macOS에서 키보드와 마우스 입력을 녹화하고 원하는 만큼 반복하는 간단한 매크로 앱입니다.

[**다다닥 다운로드**](https://github.com/Siwolmoon/Dadadak-App/releases/latest)

**지원:** macOS 27 이상 · Apple Silicon(M 시리즈)

## 기능

- 키보드 녹화·재생과 녹화/실행 단축키 지정
- 반복 횟수 설정: 0은 무한 반복, 루프 사이 대기 시간은 최소 0초
- 첫 입력부터 녹화하고 앞뒤 빈 대기 시간은 자동 제거
- 마우스 이동 좌표·클릭·드래그·스크롤 녹화 선택
- 매크로 파일 저장·불러오기와 부드러운 시작·종료음
- 가상키 매크로: 가상 HID 키보드 입력으로 재생

## 설치와 사용

1. Releases에서 DMG를 내려받아 열고 **다다닥.app**을 **Applications**에 넣습니다.
2. 시스템 설정에서 다다닥의 **손쉬운 사용**과 **입력 모니터링** 권한을 허용합니다.
3. 앱에서 녹화·실행 단축키를 지정하고, 대상 앱으로 이동해 녹화합니다. 같은 녹화 단축키로 종료합니다.
4. 반복 횟수를 정한 뒤 실행 단축키로 재생합니다. **⌘⌥Esc**는 즉시 중지입니다.

이 배포본은 Developer ID 서명·공증을 받지 않았습니다. macOS가 실행을 차단하면 **시스템 설정 → 개인정보 보호 및 보안**에서 차단된 다다닥의 **확인 없이 열기(Open Anyway)**를 선택하세요.

## 가상키 매크로는 무엇인가요?

GeForce NOW처럼 일반 매크로가 보내는 소프트웨어 키보드 입력을 받지 않는 환경에서 사용하기 위한 기능입니다. **가상키 매크로**를 켜면 Karabiner의 가상 HID 장치를 통해 실제 키보드와 같은 방식의 입력을 보냅니다. 일반 입력 경로의 제약을 우회하려는 용도이며, 서비스·게임별 지원 여부에 따라 동작이 달라질 수 있습니다. 모든 게임의 입력 제한을 해제하는 기능은 아닙니다.

- 일반 매크로는 다다닥만으로 사용할 수 있습니다. **가상키 모드는 [Karabiner-Elements](https://karabiner-elements.pqrs.org/)의 VirtualHIDDevice 8.x 드라이버 설치·활성화가 필요합니다.** [설치 안내](https://karabiner-elements.pqrs.org/docs/getting-started/installation/)
- 가상키 버튼을 처음 켤 때 관리자 승인으로 도우미를 설치합니다. 같은 앱 빌드에서는 다시 켜거나 앱·컴퓨터를 재시작할 때 기존 승인을 재사용합니다. 앱 업데이트 후에는 재승인이 필요할 수 있습니다.
- 가상 HID 모드는 키보드 전용입니다. 마우스 입력은 일반 방식으로 재생합니다.
- 도우미 제거: **파일 → 가상키 도우미 제거…**

외부 오픈소스 구성요소의 고지는 [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)에 있으며 다운로드 파일에도 포함했습니다.
